## Завдання

1. Створити новий консольний проєкт `lab23`.
2. Реалізувати початкову структуру (порушує ISP та DIP):
   - Оберіть один із варіантів завдань (System Monitor, Smart Home Hub, Payment System, MultiFunctionPrinter тощо)  
   - Реалізуйте необхідні класи та залежності  
   - Створіть головний клас, який створює свої залежності всередині себе (жорсткий зв’язок) і використовує методи, які йому можливо не потрібні
3. Проаналізувати порушення:
   - Визначте, де порушується **ISP** (клієнт залежить від методів, які не використовує)  
   - Визначте, де порушується **DIP** (модулі вищого рівня залежать від модулів нижчого рівня)
4. Виконати рефакторинг:
   - **ISP:** Виділити вузькоспеціалізовані інтерфейси  
   - **DIP:** Замінити створення залежностей на впровадження через конструктор
5. Продемонструвати роботу:
   - В `Main` сконфігурувати залежності та передати їх у головний клас  
   - Викликати основні методи для перевірки працездатності
6. Підготувати звіт:
   - Аналіз коду до рефакторингу  
   - Опис змін (нові інтерфейси, впровадження залежностей)  
   - Висновки
