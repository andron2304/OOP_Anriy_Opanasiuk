# Student Course Registration System - Vision

## Project Name
Student Course Registration System

## Problem Description
The system helps students register for university courses, check course availability, view their registered courses, and manage enrollments. It addresses the need for efficient course registration without conflicts and provides administrators with tools to manage courses.

## Target Users
- Students: Can browse courses, register, view schedules
- Administrators: Can add courses, view registrations, manage system

## Main Usage Scenarios
1. Student browses available courses and registers for a course
2. Student views their registered courses and schedule
3. Administrator adds a new course to the system
4. Student checks course availability before registration

## Non-Functional Requirements
- Code readability and maintainability
- High testability with unit tests
- Error recovery and proper exception handling
- Easy extensibility for future features

## Iteration 1 Limitations
- No persistent storage (in-memory only)
- Console-based interface only
- No user authentication
- Basic error handling
