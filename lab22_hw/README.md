## 1. Що треба було зробити
Написати клас із 5 полями, зберегти його дані (серіалізувати) у формати JSON та XML, а потім порівняти, чим вони відрізняються на вигляд.

## 2. Код мого класу

```csharp
public class Student
{
    public int Id { get; set; }
    public string Name { get; set; }
    public int Age { get; set; }
    public string Major { get; set; }
    public double AverageGrade { get; set; }
}
```

## 3. Що вийшло після серіалізації

### Ось так виглядає JSON:
```json
{
  "Id": 101,
  "Name": "Андрій",
  "Age": 18,
  "Major": "Інженерія програмного забезпечення",
  "AverageGrade": 95.5
}
```

### А ось так виглядає XML:
```xml
<?xml version="1.0" encoding="utf-16"?>
<Student xmlns:xsi="[http://www.w3.org/2001/XMLSchema-instance](http://www.w3.org/2001/XMLSchema-instance)" xmlns:xsd="[http://www.w3.org/2001/XMLSchema](http://www.w3.org/2001/XMLSchema)">
  <Id>101</Id>
  <Name>Андрій</Name>
  <Age>18</Age>
  <Major>Інженерія програмного забезпечення</Major>
  <AverageGrade>95.5</AverageGrade>
</Student>
```

## 4. Порівняння
Якщо подивитися на тексти вище, різниця дуже помітна:
* **JSON** — дуже короткий і зручний. Тут просто є фігурні дужки і значення (наприклад, `"Age": 20`). Його легко читати і він займає мало місця.
* **XML** — займає набагато більше місця. Для кожного значення він створює відкриваючий і закриваючий тег (наприклад, `<Age>20</Age>`). Через це тексту стає більше, зате системі дуже просто зрозуміти структуру документа.

## 5. Де це використовують у реальному житті?

**Де потрібен JSON:**
1. Для створення веб-сайтів і додатків (коли браузер або телефон просить дані з сервера).
2. Для збереження налаштувань програм (щоб програма пам'ятала, які кнопки ти натискав).

**Де потрібен XML:**
1. У великих і старих корпоративних системах (наприклад, на заводах чи підприємствах).
2. Для банківських переказів або податкових звітів, де потрібна дуже сувора перевірка кожної літери.

## 6. Висновок
**Чому JSON рулить в інтернеті, а XML — у банках?**
JSON зараз використовують майже скрізь у вебі. Він легкий, займає мало місця, тому сайти завантажуються швидше. До того ж, браузери ідеально його розуміють без зайвих зусиль. 

Але XML нікуди не зник. Банки та державні установи люблять XML, бо він дуже суворий. В ньому є спеціальні правила, які ретельно перевіряють документ і не дають програмі пропустити помилку чи зламатися. Тобто JSON — це про швидкість і зручність, а XML — про максимальну надійність.
