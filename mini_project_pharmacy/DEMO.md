# Demo

## Кроки демонстрації
1. Відкрийте `mini_project_pharmacy.sln` або запустіть через `dotnet run`.
2. Оберіть опцію `1` для перегляду звіту по запасах.
3. Оберіть опцію `2`, введіть ідентифікатор та кількість для замовлення.
4. Оберіть опцію `3` для поповнення запасів.
5. Оберіть опцію `4` для зведеного звіту.
6. Завершіть роботу опцією `0`.
