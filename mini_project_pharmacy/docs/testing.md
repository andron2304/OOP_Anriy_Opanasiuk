# Testing

## Структура тестів
- `tests/mini_project_pharmacy.Tests` — unit та integration тести.
- Тестові сценарії охоплюють: обробку замовлення, перевірку рецепта, роботу з запасами, збереження інвентарю.

## Як запускати

```powershell
dotnet test mini_project_pharmacy.sln
```

## Основні категорії
- позитивні випадки: створення замовлення, поповнення запасів
- негативні випадки: недостатній запас, некоректний GUID, помилкові рецепти
- інфраструктурні тести: зчитування і запис JSON у `data/inventory.json`
