# Extension Plan

## Можливі розширення проєкту

### Делегати та Pipeline
- Додати обробку замовлень через pipeline делегатів
- Реалізувати retry-логіку для операцій persistence
- Додати event-based систему для сповіщень

### Колекції
- Використовувати `Queue<T>` для черг замовлень
- Додати `Stack<T>` для історії операцій
- Кешування часто запитуваних медикаментів через `Dictionary<Guid, Medicine>`

### Асинхронний I/O
- Переписати `JsonPersistenceService` на асинхронні операції
- Додати `async/await` для читання/запису файлів
- Реалізувати асинхронний консольний цикл

### Додаткові Патерни
- Observer — сповіщення при змінах запасів
- Decorator — додаткова функціональність до замовлень (доставка, обгортка)
- Facade — спрощена демонстрація системи

### LINQ Extensions
- Кастомні методи розширення для фільтрації медикаментів
- Пошук по атрибутах (ціна, тип, тощо)

### Performance & Analytics
- Звіти по популярним медикаментам
- Аналіз витрат по категоріям
- Экспорт в CSV/Excel
