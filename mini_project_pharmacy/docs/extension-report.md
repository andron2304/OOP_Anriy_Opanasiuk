# Extension Report

## Реалізовані розширення

### В поточній версії
- Консольний інтерфейс з українською мовою
- JSON persistence з автоматичним створенням директорії
- Репозиторій з LINQ-запитами
- Обробка помилок на рівні домену

### Готові до розширення
- Структура дозволяє легко додати асинхронні операції
- Інтерфейси дозволяють замінити JSON на SQL чи інший storage
- Стратегія ціноутворення легко розширюється новими типами знижок

### Хорошою кандидатурою для наступної итерації
- Асинхронна обробка замовлень
- Кешування часто вживаних даних
- События та спостереження (Observer pattern)
