# Syllabus Coverage

- Абстракції: інтерфейси `IInventoryRepository`, `IPersistenceService`, `IPricingStrategy`
- Generics і колекції: `List<T>`, `IReadOnlyCollection<T>`
- LINQ: `.Where()`, `.Select()`, `.FirstOrDefault()`
- Обробка помилок: `DomainException`, перевірка введення
- SOLID: залежність від абстракцій, відкритість для розширення, інкапсуляція
- Патерни: Repository, Strategy, Adapter
- UML: `class-diagram.md`, `sequence-diagram.md`
- Тестування: unit та integration тести
- Рефакторинг: розділення на шари
