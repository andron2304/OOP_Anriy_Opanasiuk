# Defense Q&A

## Типові питання
1. Що реалізовано в проекті?
2. Які шари присутні в архітектурі?
3. Як працює збереження даних?
4. Які тести додані і що вони покривають?
5. Які виклики були під час розробки?

## Приблизні відповіді
- Це консольна аптечна система з розділенням на Domain / Application / Infrastructure / Console.
- Інвентар зберігається в JSON-файлі `data/inventory.json` через `JsonPersistenceService`.
- Використано патерни Repository, Strategy, Adapter.
- Тести перевіряють логіку замовлень, роботу з інвентарем і запис/зчитування JSON.
- Головні виклики: приведення до одного цілого `.NET 10` рішення та усунення зайвого фронтенду.
