# User Guide

## Мета
Коротка інструкція для користувача про запуск та основні сценарії.

## Запуск
1. Відкрийте рішення `mini_project_pharmacy.sln` в Visual Studio або використайте `dotnet run`.
2. Виберіть проект `mini_project_pharmacy.Console` як стартовий.

## Команди у програмі
- `1` — звіт по запасах
- `2` — обробка рецептурного замовлення
- `3` — поповнення медикаментів
- `4` — зведення по складу
- `0` — вихід

## Де зберігаються дані
- Дані інвентарю зберігаються у `data/inventory.json`.
- При першому запуску файл створюється автоматично.
